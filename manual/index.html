GUIA DO PROJETO

Comece com o PlantCare

Entenda como o aplicativo está organizado, prepare o ambiente de desenvolvimento e descubra como executar e manter o projeto.

O que você vai aprender
  • Preparar o ambiente Flutter.
  • Instalar as dependências do projeto.

O que é o PlantCare?

PlantCare é um aplicativo de organização dos cuidados com plantas. Ele reúne informações como nome, espécie, rega e iluminação, além das outras funcionalidades disponíveis na versão atual.

Este manual foi criado para ajudar uma pessoa que ainda não conhece o projeto a compreender sua estrutura e realizar alterações com mais segurança.

1. Pré-requisitos

Antes de executar o projeto, confira se você possui:

  • Flutter SDK instalado e configurado.
  • Visual Studio Code com as extensões Flutter e Dart.
  • Git instalado, caso vá clonar o repositório.
  • Google Chrome, para executar a versão web.
  • A configuração Firebase usada pelo projeto.
  • Conexão com a internet para acessar os serviços Firebase.

Consulte também o guia oficial de instalação do Flutter .

2. Instalação do projeto

Abra o projeto no VS Code. O terminal precisa estar na pasta principal, onde se encontra o arquivo pubspec.yaml.

1

Abra a pasta correta

No VS Code, selecione a pasta raiz do PlantCare.

2

Instale as dependências

Execute este comando no terminal:

flutter pub get
3

Confira a configuração

Para verificar o ambiente Flutter, execute:

flutter doctor

3. Executando o aplicativo

Para iniciar o PlantCare no Google Chrome, utilize:

flutter run -d chrome
Dica

Durante o desenvolvimento, salve os arquivos e utilize o hot reload quando disponível. Se ocorrer um erro, consulte primeiro a mensagem exibida no terminal do VS Code.

4. Estrutura do código

O código é separado em arquivos com responsabilidades diferentes. A estrutura exata deve ser conferida na versão atual do repositório.

│   └── services/

5. Telas do aplicativo

Login e cadastro

As telas de autenticação são responsáveis por permitir a entrada e, quando implementado, o registro de novos usuários. Os formulários devem validar os campos e apresentar mensagens adequadas.

Início

A tela inicial apresenta os principais acessos e informações disponíveis para o usuário.

Plantas

A área de plantas organiza os registros com informações como nome, espécie, rega e iluminação. Consulte a interface atual para verificar quais operações de cadastro, edição e exclusão estão disponíveis.

Histórico e perfil

Essas áreas disponibilizam as funcionalidades de histórico e configurações de perfil existentes na versão do aplicativo.

6. Firebase e armazenamento de dados

O projeto utiliza Firebase para os recursos configurados. O Firebase Authentication gerencia a autenticação quando habilitado, enquanto o Cloud Firestore armazena documentos na nuvem. 

users/
  ID_DO_USUARIO/
    plantas/
      ID_DA_PLANTA
    historico/
      ID_DO_REGISTRO

Os caminhos acima representam a organização dos dados usada pelo projeto. Os documentos de plantas e histórico pertencem à área identificada pelo usuário.

Segurança

As regras do Firestore devem restringir a leitura e a escrita aos dados permitidos para cada usuário autenticado. Nunca utilize regras públicas como solução permanente para erros de permissão.

7. Guia de manutenção

Alterar cores e aparência

Localize no código Flutter o tema utilizado pelo aplicativo. Atualize as cores, salve o arquivo e teste as telas para conferir contraste, legibilidade e consistência visual.

Adicionar uma tela

  1. Crie o arquivo da tela na pasta apropriada.
  2. Implemente os componentes e as ações necessárias.
  3. Conecte a tela ao sistema de navegação.
  4. Teste os caminhos de entrada e retorno.

Adicionar um campo às plantas

  1. Atualize o modelo de dados.
  2. Inclua o campo nos formulários necessários.
  3. Atualize a gravação e a leitura no Firestore.
  4. Considere como os documentos antigos serão tratados.
  5. Teste cadastro, consulta, edição e exclusão.

Verificar alterações

Antes de registrar uma mudança, execute:

flutter pub get
flutter analyze
flutter run -d chrome

8. Solução de problemas

O aplicativo não abre

Confira a saída do terminal, execute flutter analyze e verifique se as dependências estão instaladas.

Erro de permissão no Firestore

Confirme a autenticação, o caminho dos documentos e as regras de segurança aplicadas ao banco de dados.

As plantas não aparecem

Verifique a conexão, o usuário autenticado, a leitura do Firestore e as permissões de acesso.
